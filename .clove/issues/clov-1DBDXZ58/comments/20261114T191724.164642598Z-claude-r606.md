The guard is now `cargo xtask guard-sdk-licenses` (xtask/src/guards.rs). It checks normal, build and dev edges for each SDK crate with default and all features, fails on a crate with no license, and reads SPDX expressions (`A OR B` is copyleft only when both sides are). Dev edges bring in r-efi (MIT OR Apache-2.0 OR LGPL-2.1-or-later), which a grep for GPL would reject and the expression reader accepts. Check: `cargo test -p xtask`: guards::tests 10 passed; `cargo xtask guard-sdk-licenses` prints "ok: no copyleft or unlicensed crate in the SDK dependency trees".
