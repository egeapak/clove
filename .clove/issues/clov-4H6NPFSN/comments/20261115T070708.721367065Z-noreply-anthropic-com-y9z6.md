The ubuntu and macOS test jobs gain a 'Lean daemon smoke' step: cargo build -p clove-cli -p cloved (default features), then CLOVE_SMOKE_WEB=0 scripts/ci/daemon-smoke.sh target/debug. With CLOVE_SMOKE_WEB=0 the script requires that the daemon serves no web UI, so it cannot pass on a web build. Local run on the lean build: 'daemon smoke: all checks passed'. On a web build, CLOVE_SMOKE_WEB=0 fails with 'the daemon serves a web UI ... (not a lean build?)', exit 1; the default mode still passes there.
