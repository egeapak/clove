resolve_runtime_dir keeps CLOVE_RUNTIME_DIR, then XDG_RUNTIME_DIR/clove, then $TMPDIR|/tmp/clove-<uid>. When that last directory already exists and is not a private directory of the current user, the runtime directory is <clove-home>/run instead, so the daemon can start. With no clove home the old path stays and the daemon refuses it as before.
