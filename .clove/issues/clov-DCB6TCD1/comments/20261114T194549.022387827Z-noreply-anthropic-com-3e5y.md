Implemented option (a): clove_web::WebAuth, a random token per clove serve and per hub. A request without it is 401. The printed URL carries ?token=; a page load sets the cookie clove_web_<port> (HttpOnly, SameSite=Strict) and redirects to the URL without the token; scripts send Authorization: Bearer or ?token= on the API request. clove serve prints the token URL, and the daemon's web_url carries it. No SPA change.
