crates/clove/tests/support/mod.rs has isolated_env(dir), which sets CLOVE_RUNTIME_DIR and CLOVE_HOME under the test's own directory. The 20 suites that spawn clove without their own runtime directory now pass it to every spawn. HOME is not changed, because git and cargo in the suites read it, and clove reads HOME only to find the clove home.
