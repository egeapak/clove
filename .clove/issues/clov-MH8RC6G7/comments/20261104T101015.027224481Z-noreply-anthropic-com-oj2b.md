Root cause: the hub's empty-grace timer runs from hub start. The old test used a 200 ms grace, so under load the grace ran out before the test's first load arrived; the hub exited and cut that attach ('connection to the server was already shutdown'). Commit 0ddf475 (#106) made the test hold both idle timers with CLOVED_IDLE_HOLD_FILE until the project is loaded. A user start is not affected: ensure_daemon_at retries a Transport or SHUTTING_DOWN answer from an exiting hub, and the default grace is 60 s. Check: daemon_lifecycle an_idle_hub_exits_after_its_projects_idle_out passes 20/20 with 8 CPU burners on 4 cores.
