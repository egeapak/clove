run_round.sh now takes --runs N (default 3) and --model M, writes <out>/<model>/<scenario>/r<k>/, and the default AGENT_CMD loads only project settings so user hooks do not act on a rollout. New aggregate.py prints the mean, minimum, and run count per scenario and model (plain or --markdown); a run without score.json is reported as missing. Verified with AGENT_CMD=true --runs 2 on s3 and s12 (n=2 per cell) and a hand-made two-model tree. The README documents both, plus the subagent route for environments that block a script from starting an agent.
