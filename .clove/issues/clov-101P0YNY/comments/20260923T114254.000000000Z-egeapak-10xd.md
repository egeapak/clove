Design approved 2026-07-24; spec at docs/superpowers/specs/2026-07-24-crates-io-plugin-registry-design.md.

Replaces the curated registry/plugins.toml (PLUGIN_REGISTRY.md §1/§4/§5) with crates.io itself. Discovery = GET /crates/clove-plugin/reverse_dependencies (authoritative, unspoofable); resolution = exact name probe on clove-<mux>-<source> (crates.io has NO prefix search: q=clove-sync returns 0). Plus a plain-git install path for unpublished plugins.

Transport: in-app ureq with rustls pinned to ring, always on. Measured +1.011 MB on the real binary (6.349 -> 7.360 MB), verified with a live TLS call. Ring pin is load-bearing: default-features rustls unified onto aws-lc-sys and tripled a probe binary (0.73 -> 2.49 MB).

crates.io publishing is DEFERRED. Phases 1-2 (name probe, git install, install/uninstall/update, cache) are buildable and testable now; Phase 3 (live discovery) activates when clove-plugin is published, with no redesign.
