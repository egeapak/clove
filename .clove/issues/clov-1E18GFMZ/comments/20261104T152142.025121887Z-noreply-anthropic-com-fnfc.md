Done in PR #183. .config/nextest.toml runs the setup script 'cargo xtask test-bins' (xtask/src/main.rs) for package(clove-cli). It runs cargo build --profile test --workspace --all-features --bins --tests into target/test-bins with the workspace build dir, so after nextest's own build it compiles nothing; it strips the variables cargo run and nextest add (CARGO_PKG_*, CARGO_MANIFEST_DIR, target dirs on LD_LIBRARY_PATH/PATH), because ring's build script tracks CARGO_MANIFEST_DIR and the two builds otherwise rebuilt each other. It copies the plugins beside target/debug/clove and writes CLOVE_TEST_BIN_DIR to NEXTEST_ENV. support::cloved()/plugin() only look the binaries up; escargot is removed. cargo xtask test-all runs nextest and then cargo test --doc; CLAUDE.md, README.md, docs/RELEASE.md, docs/RELEASE_CHECKLIST.md, ci.yml and .woodpecker/lint-test.yml use nextest. plugin_install.rs kept its isolated clove copy in a static TempDir, which is never dropped, so under nextest every test leaked a 77 MB copy in the temp dir; it is now a hard link (copy as fallback) inside each test's own temp dir.
